# 🤖 AI Mock Interviewer

A fully functional AI-powered mock interview platform built with **Python**, **Streamlit**, and **Google Gemini 2.5 Flash**.

### 🚀 Live Demo
[Click here to try the App](LINK_TO_YOUR_STREAMLIT_APP)

### ✨ Features
- **📄 Smart Resume Analysis:** Uses `pypdf` to extract text and `Gemini AI` to calculate an **ATS Match Score** against the Job Description.
- **🧠 Context-Aware Questions:** The AI generates technical questions based specifically on the candidate's missing skills and project gaps.
- **🎨 Cyberpunk UI:** Custom CSS styling for a modern, dark-mode interface.
- **🗣️ Adaptive Feedback:** Provides real-time feedback and a final performance review upon request.

### 🛠️ Tech Stack
- **Frontend:** Streamlit
- **AI Model:** Google Gemini 2.5 Flash
- **PDF Processing:** PyPDF2
- **Environment Management:** Python-dotenv
